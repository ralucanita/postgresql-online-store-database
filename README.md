# PostgreSQL Online Store Database

This is my first PostgreSQL project.

I created a simple database for an online store to practice what I've learned about SQL and PostgreSQL.

## What I used

- Tables
- Primary and foreign keys
- Constraints
- Identity columns
- Different PostgreSQL data types
- ALTER TABLE
- CHECK and DEFAULT
- Table relationships

## Tables

The database has tables for customers, categories, products, orders and order items.

I will keep updating this project as I learn more SQL.
